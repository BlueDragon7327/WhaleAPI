# WhaleAI 🐋

### Fully Open Source Self-Hosted site for AI models such as GPT, Claude, and Gemini. (Powered by [MiraAI](https://discord.gg/wukzZbJvQj)



## How to use?

*MAKE SURE YOU HAVE PYTHON INSTALLED*

* Download this repo as a zip.
* Extract it.
* In the extracted folder, open key.txt and paste in your MiraAI API key (OBTAIN API KEY BY RUNNING /getkey IN [MiraAI's Discord](https://discord.gg/wukzZbJvQj))
* After adding your API key, run whale.bat, then it should say "WhaleAI running on: http://127.0.0.1:5000", just open that url and you're set!
